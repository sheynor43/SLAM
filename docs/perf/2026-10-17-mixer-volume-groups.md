# Микшер: группы громкости и плавная общая громкость

- Дата: 2026-10-17
- Задача: [#162](https://github.com/sheynor43/SLAM/issues/162), решение — [ADR-0046](../adr/0046-mixer-volume-groups.md).
- Итог: **общий путь (переходы громкости, баланс, дробная скорость) не изменился. Быстрый путь медленнее на ~10 нс на буфер из 128 кадров (+5–6 %)**. Это ~0,0004 % длительности буфера (2,7 мс при 48 кГц), бюджет аудиоколбэка (ARCHITECTURE §18) не затронут.

## Машина
Ryzen 7 5700X, Linux 7.2.9-2-cachyos, release-профиль `cargo bench`.

## Команда
```
cargo bench -p slam-audio --bench mixer -- --save-baseline before   # на main
cargo bench -p slam-audio --bench mixer -- --baseline before        # на ветке
```

## Откуда разница
- На каждый буфер считаются шины групп (общая × группа) и сдвигаются их переходы: ~2 нс.
- На каждый голос: выбор шины по группе и проверка, что она не в переходе: ~1,6 нс.

Первая версия была медленнее: общий путь +19 %, быстрый +8 %. Помогли три правки:
- шины считаются один раз на буфер, а не на каждый голос;
- число кадров делится один раз на буфер;
- цикл по кадрам работает с локальными копиями и отдельной версией для шины в переходе. Громкость перехода считается обратным счётчиком кадров, как в прежнем коде.
