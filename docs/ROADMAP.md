# SLAM — дорожная карта

Каждый этап заканчивается проверяемыми критериями. Этап не считается завершённым, пока критерии не выполнены в CI или не зафиксированы бенчмарком.

Текущие задачи — в [milestones и issues](https://github.com/sheynor43/SLAM/milestones) на GitHub.

Закрытый этап поднимает minor версии: M2 → `0.1.0-alpha`, M3 → `0.2.0-alpha` и т. д. ([ADR-0106](adr/0106-version-per-milestone.md)).

| Этап | Состояние |
|---|---|
| M0, M1 | закрыты |
| M2 | закрыт, выпущен как [v0.1.0-alpha](https://github.com/sheynor43/SLAM/releases/tag/v0.1.0-alpha) |
| M3 | текущий |

## M0 — Фундамент движка

**Цель:** проверить, что выбранный стек держит целевые цифры, до того как на него опирается всё остальное.

- Workspace, `rust-toolchain.toml`, CI (fmt, clippy, test, deny), `THIRD_PARTY_NOTICES`.
- `slam-input`: окно SDL3, input-поток с таймстемпами событий.
- `slam-render`: HAL + бэкенд OpenGL 3.3, батчер спрайтов, трансляция шейдеров через `naga`.
- `slam-engine`: update/draw-потоки, тройной буфер, лимитер с абсолютными дедлайнами, оверлей фреймтайма.
- `slam-audio`: HAL + WASAPI (shared, low-latency, exclusive) + PipeWire, тестовый тон и сэмпл по клику.
- Бенчмарк-сцена: пустой кадр + 500 спрайтов.

**Готово, когда:** ≥ 8000 FPS на бенчмарк-сцене; p99 джиттера лимитера < 50 мкс; клик → звук измерен и задокументирован; принято решение о D3D11/Vulkan (новый ADR).

Состояние критериев:
- [x] ≥ 8000 FPS на бенчмарк-сцене — X11 ~14 400, Wayland ~12 200 ([замер](perf/2026-10-10-present-stalls.md); первый [замер](perf/2026-10-10-bench-scene.md) снят при работающей записи экрана).
- [x] p99 джиттера лимитера < 50 мкс — ≤ 1 мкс ([изолированно](perf/2026-10-08-frame-limiter.md), [в цикле отрисовки](perf/2026-10-10-bench-scene.md)).
- [x] Клик → звук измерен и задокументирован — [#26](https://github.com/sheynor43/SLAM/issues/26), [отчёт](perf/2026-10-10-click-to-sound.md): ввод → очередь 37 мкс (p50), щелчок → звук 25.4 мс на USB-интерфейсе; задержку устройства PipeWire сообщает не полностью.
- [x] Решение о D3D11/Vulkan — [ADR-0024](adr/0024-render-backend-per-platform.md).
- [x] WASAPI — [#10](https://github.com/sheynor43/SLAM/issues/10), [ADR-0027](adr/0027-wasapi-backend.md): проверено сборкой и CI на Windows без звукового устройства; ручная проверка на Windows — [#35](https://github.com/sheynor43/SLAM/issues/35).
- [x] Задержки `present` на Linux — [#28](https://github.com/sheynor43/SLAM/issues/28): причина — конкуренция за очередь GPU с записью экрана (OBS), прототип Vulkan не нужен ([отчёт](perf/2026-10-10-present-stalls.md)).

## M1 — Ядро без графики

- `slam-formats`: `.osu`, `.osr` + блок лазера, `.osz`.
- `slam-osu`: конвертация и обработка карты, слайдеры, хит-окна, политика попаданий, здоровье, standardised scoring, базовые моды (NF, HD, TC, DT/HT с кастомной скоростью, DA, Mirror, Classic), интерфейс `GameplayMod`.
- Симулятор реплея без графики; инфраструктура корпусов.

**Готово, когда:** корпус лазерных реплеев совпадает 1:1; тест «ноль аллокаций» для update-тика проходит.

Состояние критериев:
- [x] Корпус лазерных реплеев совпадает — по правилам [ADR-0029](adr/0029-live-play-replay-model.md): круги 1:1, хвосты, тики и бонусы в допуске, потому что живой счёт из 60-Гц кадров реплея точно не восстанавливается. 49 реплеев: 40 совпали, 8 в допуске, 1 известное расхождение, 0 строгих расхождений ([отчёт](perf/2026-10-11-lazer-corpus-parity.md), [#54](https://github.com/sheynor43/SLAM/issues/54)).
- [x] Ноль аллокаций в шаге симуляции — на всех реплеях корпуса и в синтетических тестах со всеми типами объектов и модами ([отчёт](perf/2026-10-11-lazer-corpus-parity.md)).

## M2 — Играбельный геймплей

- Отрисовка объектов на дефолтном скине, тела слайдеров, курсор.
- Аудиоклок с учётом задержки устройства, офсеты, хитсаунды.
- Минимальные экраны: выбор карты из папки, игра, результаты.
- Инфраструктура локализации (Fluent, en + ru) — с самого начала, все строки через ключи.
- Бэкенд рендера D3D11 на Windows, с замером бенчмарк-сцены против OpenGL ([ADR-0024](adr/0024-render-backend-per-platform.md), [#29](https://github.com/sheynor43/SLAM/issues/29)).

**Готово, когда:** карты играются от начала до конца; ощущения по таймингу сравнимы с лазером при одинаковом офсете (ручная проверка + сравнение реплеев).

Состояние: закрыт, выпущен как [v0.1.0-alpha](https://github.com/sheynor43/SLAM/releases/tag/v0.1.0-alpha) (список изменений — `packaging/release-notes.md`).
- Рендер на Windows: по замерам основным стал OpenGL, Direct3D 11 — настройка с откатом ([ADR-0104](adr/0104-renderer-setting-opengl-default.md), [ADR-0105](adr/0105-opengl-handoff-retry-and-fallback.md)).
- Сделано сверх плана: панель и хоткеи модов, кастомная скорость ([ADR-0055](adr/0055-rate-mods-in-play.md)–[ADR-0057](adr/0057-mod-settings-panel.md)); запись реплеев своих попыток, в том числе проваленных ([ADR-0084](adr/0084-save-failed-replay.md)); поиск с языком запросов лазера ([ADR-0099](adr/0099-search-query-language.md)); музыка в меню и превью ([ADR-0090](adr/0090-menu-music.md)); панель настроек со сменой звука, языка, скина без перезапуска; шкала ошибок, счётчик FPS, меню паузы и провала; альфа-сборки zip и AppImage ([ADR-0068](adr/0068-alpha-release-packaging.md)).

## M3 — Скины

- `skin.ini` всех версий, `@2x`, анимации, фолбэки.
- Реестр элементов, слоистая сборка, меню сборки скина.
- Горячая перезагрузка скинов, импорт `.osk`.
- Элементы скина вне игрового поля: HUD (здоровье, комбо, точность), отсчёт и служебные элементы, меню паузы и провала, экран результатов, эффекты. Вид stable, которого нет в лазере, — по McOsu ([ADR-0107](adr/0107-license-gpl3-and-mcosu.md)).
- Раскладки HUD отдельно от скина ([ADR-0061](adr/0061-hud-layout-presets.md)): пресеты stable/lazer/SLAM, «Дублировать», свои спрайты, экспорт и импорт, импорт раскладок лазера ([#216](https://github.com/sheynor43/SLAM/issues/216)). Перенесено из M5: без раскладок скины лазера не загружаются целиком.
- Скриншот-тесты и локальный корпус эталонных скинов (чужие скины в репозиторий не кладутся).

Уже есть с M2: разбор `skin.ini`, цепочка «скин карты → скин пользователя → классический дефолт» с `@2x`, кадрами и фолбэками ([ADR-0058](adr/0058-default-skin-chain.md)), выбор скина из папки `Skins` ([ADR-0051](adr/0051-stable-skin-selection.md)), смена скина в паузе ([ADR-0096](adr/0096-live-skin-swap.md)).

**Готово, когда:** набор популярных stable-скинов выглядит корректно (список эталонных скинов и скриншоты в тестах); элемент из другого скина интерпретируется по правилам своей версии.

## M4 — Библиотека и выбор песни

- Своё хранилище, SQLite, снапшот `rkyv`, миниатюры, кеш звёзд.
- Открытие `.osz`, ассоциации файлов.
- Опциональный импорт: stable (на месте, инкрементально), lazer (`tools/lazer-export` + хардлинки), коллекции.
- Вложенные коллекции: коллекция может содержать другие коллекции (например, `nm` → `aim`, `farm`, `stream`).
- Импортированные коллекции раскладываются по двум корневым: `stable` и `lazer`; внутри — коллекции в исходном виде.
- Выбор песни: сортировки, виртуализированная карусель, звёзды на `rosu-pp`; данные для оставшихся ключей поиска ([#309](https://github.com/sheynor43/SLAM/issues/309)).
- Офсет карты в библиотеке ([#175](https://github.com/sheynor43/SLAM/issues/175)).
- Локальные профили.

Уже есть с M2: поиск с языком запросов ([ADR-0099](adr/0099-search-query-language.md)), превью музыки ([ADR-0090](adr/0090-menu-music.md)), фон и характеристики выбранной карты, перетаскивание списка ([ADR-0093](adr/0093-song-list-drag.md)), выбор папки песен ([ADR-0064](adr/0064-songs-folder-picker.md)).

**Готово, когда:** бюджеты из раздела 18 ARCHITECTURE для библиотеки на 100k сложностей выполнены; клиент полностью работает без установленных stable и lazer.

## M5 — HUD

- Компоненты HUD (полный стартовый набор), pp-каунтер на `rosu-pp`.
- Редактор раскладки: правка любого элемента (положение, размер, поворот, прозрачность, перспектива, спрайт). Сами раскладки и импорт HUD JSON лазера — в M3.
- Реестр шрифтов, пользовательские шрифты. Текстовый стек и MSDF уже есть ([ADR-0037](adr/0037-text-stack.md), [ADR-0062](adr/0062-own-msdf-generator.md)).

**Готово, когда:** раскладки популярных лазерных скинов загружаются; все компоненты настраиваются через редактор.

## M6 — Реплеи

- Просмотр реплеев stable и lazer: перемотка вперёд и назад (снапшоты состояния каждые ~5 с), скорость воспроизведения.
- Контейнер SLAM для реплеев с кастомными модами; просмотр и экспорт сохранённых реплеев из игры.

Уже есть с M2: запись реплеев своих попыток в `.osr` с блоком лазера, в том числе проваленных ([ADR-0084](adr/0084-save-failed-replay.md)).

**Готово, когда:** корпус stable в пределах допуска; свои реплеи открываются в лазере (без кастомных модов).

## M7 — Моды, настройки, экспорт

- Интерфейс модов: цикл HD/TC. Панель модов, настройки модов, кастомная скорость и DA с хоткеями уже есть с M2 ([ADR-0056](adr/0056-song-select-mod-hotkeys.md), [ADR-0057](adr/0057-mod-settings-panel.md)).
- Экспорт `.osz`, `.osk`, `.osr`; файл настроек `.slamcfg`; резервная копия профиля.
- Мастер калибровки офсета.

**Готово, когда:** `.slamcfg` переносит настройки между двумя чистыми установками без ручных правок; секреты никогда не попадают в файл (тест).

## M8 — Плагины

- Luau-рантайм, песочница, права, бюджеты.
- `gameplay_mod` (включая генеративные с валидацией), `ui_module`, `connector`.
- Генерация типов для luau-lsp и документации; примеры; `slam mod new`; консоль и профайлер плагинов.

**Готово, когда:** встроенный HD переписан как пример на Luau и проходит те же тесты; пример лидерборд-модуля работает с тестовым коннектором и мок-сервером.

## M9 — Темы, языковые пакеты, редактор, релиз

- Темы (`theme.toml`), меню настройки темы.
- Языковые пакеты `.slamlang`, `slam i18n check`.
- JSON-RPC для внешнего редактора, режим рабочей папки; публикация крейтов.
- Установщик Windows. Портативный zip, AppImage и сборка релизов по тегу уже есть с M2 ([ADR-0068](adr/0068-alpha-release-packaging.md)).

**Готово, когда:** первая бета. Публичные альфы выходят с M2; когда переходить к бете или `1.0`, решается отдельным ADR ([ADR-0106](adr/0106-version-per-milestone.md)).
