# ADR-0147: Onest — шрифт интерфейса

- Статус: Принято
- Дата: 2026-11-15
- Заменяет ADR-0037 (в части шрифта интерфейса)

## Контекст
ADR-0037 выбрал для текста интерфейса Nunito Sans. По живой проверке мелкого узкого шрифта (#377) его вид не устроил: округлый и мягкий, он далёк от Torus, которым лазер набирает весь интерфейс. Сам Torus взять нельзя: это коммерческий шрифт (в `osu-resources` — «requires a commercial licence for distribution», остальные ресурсы там — CC-BY-NC 4.0), несовместим с GPL-3.0 (ADR-0107). Перерисовка по образцу — производная работа, тоже нет.

Сравнивались OFL-шрифты из `google/fonts` в насыщенности 600: Outfit, Figtree, Lexend, Mona Sans, Plus Jakarta Sans (без кириллицы), Manrope, Onest, Golos Text, Montserrat, Rubik, Nunito.

## Решение
- Шрифт интерфейса — **Onest** (вариативный, ось `wght` 100–900, латиница и кириллица, SIL OFL 1.1), `assets/fonts/onest/`, встроен в бинарник. `UI_FAMILY` = «Onest».
- Nunito Sans остаётся встроенным и стоит вторым в цепочке фолбэка (`[Onest, Nunito Sans]`): у Onest нет, например, «∞», а у Nunito Sans шире покрытие латиницы и есть ось `wdth`.
- Exo 2 для заголовков — без изменений.
- Оси ширины у Onest нет: мелкий текст сужается не шириной, а размером и насыщенностью, как Torus в лазере (подписи 16 SemiBold, заметки 14). Токен `caption_width` — 100; ось ширины (ADR-0146) остаётся для шрифтов, у которых она есть.

## Последствия
- Интерфейс ближе к лазеру по виду; бинарник больше на ~190 КБ.
- Глифы, которых нет в Onest, берутся из Nunito Sans — в одной строке могут встретиться два рисунка.
- Тесты, завязанные на оси Nunito Sans, обращаются к нему по имени семейства, а не через `UI_FAMILY`.

## Отвергнутые варианты
- Torus из `osu-resources` или его перерисовка — лицензия.
- Outfit (ближе всех к Torus по рисунку) и другие без кириллицы — русский интерфейс шёл бы фолбэком.
- Manrope — близок, но уже и строже; Golos Text и Rubik — тяжелее; Montserrat — слишком широкий для мелких подписей.
- Оставить Nunito Sans — не устроил по виду.
