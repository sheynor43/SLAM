# ADR-0008: Скины — реестр элементов и слоистая сборка

- Статус: Принято
- Дата: 2026-10-08

## Решение
- Реестр всех скинуемых элементов: ID, категория, файлы, связанные ключи `skin.ini`.
- Профиль скина = базовый скин + правила «элемент → источник», в JSON; исходные скины не меняются.
- Единица замены — элемент вместе с зависимостями; элемент интерпретируется по версии своего скина-источника.
- Скины — обычные папки с горячей перезагрузкой.
- Дефолтный скин — классический из osu-resources (CC-BY-NC 4.0), отдельно, с атрибуцией.

## Последствия
- Меню сборки строится автоматически из реестра.
- Реестр нужно поддерживать полным; неизвестные файлы скина игнорируются с записью в лог.
