# ADR-0127: Миниатюры карт в списке до хранилища

- Статус: Принято
- Дата: 2026-11-14
- Уточняет ARCHITECTURE §9 и отменяет отказ от миниатюр в [ADR-0066](0066-song-select-background.md) до хранилища

## Контекст
ADR-0066 отложил миниатюры до хранилища (M4): их негде держать между запусками, а декодировать каждый фон при скане долго. Пользователь хочет миниатюры в строках списка рядом с названием, с разрешением из настроек или без них (#364, часть 2).

## Решение
- **Настройка** `song_select.thumbnails`: `off`, `64`, `128`, `256` — высота миниатюры в пикселях; по умолчанию `128`. Меняется на лету: другая высота сбрасывает кеш в памяти.
- **Создание по запросу.** Миниатюры делаются только для видимых строк (и нескольких рядом), а не при скане. Update просит их по кольцу у отдельного потока миниатюр (`slam-thumbnails`), берёт последние запросы, лишние отбрасывает. Поток ищет фон сложности (имя из скана, ADR-0066), декодирует, уменьшает до заданной высоты с обрезкой по пропорции строки (`cover`) и отдаёт пиксели загрузчику текстур меню (`TextureKind::Standalone`).
- **Кеш на диске:** `cache/thumbnails/<высота>/<ключ>.png`, где ключ — хеш пути фона, его размера и времени изменения. Есть в кеше — декодируется маленький PNG вместо исходного фона.
- **Кеш в памяти:** до 64 текстур миниатюр, вытеснение давно не видимых (LRU) в update; освобождение текстур — как у фонов (ADR-0066), после того как draw их больше не рисует.
- **Отрисовка.** Миниатюра — фигура строки с текстурой (ADR-0116), скруглённая по краю строки, слева от названия; пока не загружена или фона нет — плашка цвета схемы. Появляется проявлением.

## Последствия
- Первая прокрутка большой библиотеки декодирует фоны в фоне; строки сначала без картинок.
- Папка `cache/thumbnails` растёт с библиотекой (~5–30 КБ на фон на размер); очистки пока нет.
- При переходе на хранилище (M4) кеш остаётся тем же механизмом, только ключи берутся из базы.

## Отвергнутые варианты
- **Миниатюры при скане.** Долго на больших библиотеках, а большинство строк никто не увидит.
- **Атлас миниатюр.** Меньше переключений текстур, но сложнее вытеснение; при ~20 видимых строках не нужен.
