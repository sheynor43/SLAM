# ADR-0005: Правила геймплея как в lazer, движок свой

- Статус: Принято
- Дата: 2026-10-08

## Контекст
Реплей хранит только ввод; результат пересчитывается движком. Для совместимости реплеев правила должны совпадать с клиентом-источником.

## Решение
- Эталон правил — код lazer (MIT): обработка карты, слайдеры, хит-окна, политика попаданий, здоровье, скоринг.
- Типы чисел копируются буквально (`f64` время, `f32` позиции), тот же порядок операций.
- Stable-реплеи судятся как `lazer + Classic`. Точный профиль stable — только при необходимости.
- Архитектура движка (потоки, рендер, лимитер, UI) — собственная; лазер для неё не образец.

## Последствия
- Лазерные реплеи проверяются 1:1 корпусом в CI.
- Изменения правил в лазере нужно отслеживать и переносить (фиксировать версию лазера, на которую ориентируемся).
- Портированный код помечается ссылкой на исходный файл лазера.

## Отвергнутые варианты
- Правила stable по умолчанию: хуже документированы, нет исходников.
- Переключаемые профили на старте: двойная работа до появления потребности.
