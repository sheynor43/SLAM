# ADR-0152: Панель модов в стиле лазера: пять колонок, выезд снизу

- Статус: Принят
- Дата: 2026-11-16
- Дополняет ADR-0136 (цвета колонок модов)

## Контекст
Панель модов (#386) появляется сразу, без анимации, и знает три колонки: облегчение, усложнение, конверсия. В лазере (`ModSelectOverlay`, `ModColumn`, `ModPanel`) колонок пять, каждая — плашка с шапкой в цвете типа модов, и колонки выезжают по очереди. Для модов автоматизации (#385) нужна своя колонка.

## Решение
- **Колонки** — как в лазере, по порядку: облегчение, усложнение, автоматизация, конверсия, веселье (`MAX_COLUMNS = 5`). Колонка без модов SLAM не показывается: оставшиеся встают по центру (`ModSelectLayout::place`). Горячие клавиши — у первых трёх колонок, как в лазере (Q…P, A…L, Z…M).
- **Колонка** — плашка (`mod_column_fill`) с шапкой высотой `mod_column_header_height` в цвете типа модов (лазер: Lime1, Red1, Blue1, Purple1, Pink1 — `mod_column_tints`). Плашки модов — как прежде, в цвете колонки.
- **Выезд.** Открытие — колонки выезжают снизу на `mod_panel_distance` (700 при опорной высоте, как `distance` лазера) и проявляются за `mod_panel_in_ms` (400) с кривой OutQuint; каждая следующая колонка — с задержкой `mod_column_stagger_ms` (30). Закрытие — обратно вниз за `mod_panel_out_ms` (500). В лазере колонки выезжают попеременно сверху и снизу; по задаче — все снизу. Затемнение фона и заголовок проявляются без сдвига.
- Анимацию ведёт вид (поток отрисовки) по смене флага `open` в снимке, со своим временем кадра, как раскрытие сложностей. Разворот на полпути продолжает с текущего положения. Мышь и клавиши работают по итоговой раскладке сразу после открытия.

## Последствия
- Колонки автоматизации и веселья пока пусты и скрыты; автоматизация появится с #385.
- Во время выезда клик попадает по итоговому месту плашки, а не по видимому.

## Отвергнутые варианты
- **Попеременный выезд сверху и снизу, как в лазере.** Задача просит выезд снизу.
- **Показывать пустые колонки.** Пустая плашка без модов выглядит как ошибка.
- **Время анимации в снимке update-потока.** У вида уже есть своё время кадра; разворот проще считать там.
