# ADR-0134: Звёзды без модов через rosu-pp; порядок сложностей по звёздам

- Статус: Принято
- Дата: 2026-11-14
- Уточняет ARCHITECTURE §7 («pp и звёзды») и §9 до хранилища (M4)

## Контекст
Свечение сложностей (ADR-0131) берёт цвет из звёзд, а звёзд в SLAM нет. Сложности внутри сета иногда идут не по порядку: порядок — как нашёл скан.

## Решение
- **`rosu-pp`** (MIT) подключается в `slam-osu` с зафиксированной версией (ARCHITECTURE §3, §7). Обёртка `slam_osu::stars` считает звёзды без модов по файлу `.osu`.
- **Когда считается.** Отдельный поток звёзд после скана считает звёзды всех сложностей по очереди: сначала видимые сеты, затем остальные. Результат — в кеш на диске `cache/stars.bin`: ключ — хеш пути, размера и времени изменения файла, плюс версия `rosu-pp`. Готовые значения приходят в update пачками по кольцу и попадают в список без аллокаций в тике (место под звёзды выделено при публикации списка).
- **Порядок сложностей** внутри сета — по звёздам по возрастанию, как в лазере; пока звёзды не посчитаны — по OD, затем по имени сложности; при равенстве — по имени. Пересортировка сета при приходе звёзд не сбивает выделение.
- **Показ.** Звёзды на левой плашке и в строке сложности; цвет — шкала лазера (ADR-0131). С модами — позже, вместе с pp-каунтером.

## Последствия
- Первый запуск на большой библиотеке считает звёзды минуты в фоне; со второго — из кеша.

## Отвергнутые варианты
- **Свой порт калькулятора лазера.** Объёмно, а `rosu-pp` уже выбран ARCHITECTURE §7.
- **Звёзды при скане в том же потоке.** Задержало бы появление списка.
