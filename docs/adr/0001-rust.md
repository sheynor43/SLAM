# ADR-0001: Язык — Rust

- Статус: Принято
- Дата: 2026-10-08

## Контекст
Цель — производительность на уровне osu!stable или лучше, без спайков фреймтайма; кроссплатформенность; открытый код.

## Решение
Rust (stable, версия закреплена в `rust-toolchain.toml`), cargo workspace.

## Последствия
- Нет сборщика мусора — нет пауз GC.
- Готовая экосистема: `rosu-pp` (звёзды, pp, пошаговый расчёт), парсеры форматов osu!, `mlua`, `symphonia`, `rubato`, `rkyv`.
- Нужен C++-компилятор для Luau.
- Код лазера (C#) портируется вручную.

## Отвергнутые варианты
- C# на форке osu-framework: быстрый старт, но наследуется вес лазера и риск пауз GC.
- C++: сопоставимая производительность, хуже эргономика и сборка.
