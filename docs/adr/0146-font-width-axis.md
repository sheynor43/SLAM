# ADR-0146: Ось ширины вариативных шрифтов

- Статус: Принято
- Дата: 2026-11-15

## Контекст
Текстовый стек (ADR-0037) берёт у вариативных шрифтов только ось насыщенности `wght`. Мелкому тексту интерфейса (подписи настроек, подсказки, выпадающие списки, сложности) нужно узкое начертание, чтобы вмещать больше. У встроенного Nunito Sans есть ось ширины `wdth` (75–125 %), у Exo 2 её нет.

## Решение
- `TextStyle::width` — ширина в процентах от обычной (100 по умолчанию). `FontRegistry::resolve_width` зажимает её в диапазон оси `wdth` выбранного начертания; у начертания без оси ширина всегда 100, что бы ни просили (`resolve` — то же при 100).
- Ширина идёт тем же путём, что насыщенность: `ResolvedFace::width` → экземпляр шрифта с координатами `wght` и `wdth` (кеш экземпляров и планов шейпинга по паре насыщенность/ширина) → `PositionedGlyph::width` → `GlyphKey::width` → координата `wdth` при генерации MSDF.
- Размер по-прежнему не входит в ключ глифа: узкий глиф — отдельная картинка атласа, одна на все размеры.

## Последствия
- Узкий текст добавляет в атлас свои глифы: страниц может понадобиться больше, если узких строк много.
- Начертание без оси ширины не сужается — для пользовательских шрифтов без `wdth` узкий стиль выглядит как обычный.
- Стили интерфейса, которые берут узкий шрифт, — отдельная задача (токены темы).

## Отвергнутые варианты
- Отдельный узкий шрифт в комплекте — лишние мегабайты и лицензия, когда ось уже есть в Nunito Sans.
- Сжатие глифов по горизонтали при отрисовке — искажает штрихи и не меняет шейпинг.
