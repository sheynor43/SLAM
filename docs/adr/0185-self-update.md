# ADR-0185: Обновление по воздуху из выпусков GitHub с подписью ed25519

- Статус: Принято
- Дата: 2026-11-27

## Контекст
Выпуски SLAM публикуются на GitHub (`sheynor43/SLAM`): AppImage для Linux и переносной zip для Windows (`release.yml`). Обновиться можно только вручную. Пользователь хочет обновление из самой игры: спросить, затем скачать, с проверкой подписи; пока все выпуски — alpha.

## Решение
- **Проверка**: при запуске (и кнопкой в настройках) фоновый поток спрашивает GitHub Releases API о последнем выпуске; канал `updates.channel` — `prerelease` (по умолчанию, пока всё alpha) или `stable`. Версии сравниваются по semver с учётом pre-release. Без сети и при ошибке — тишина в интерфейсе, запись в лог. Выключается `updates.check`.
- **Вопрос**: о новой версии — уведомление «Доступна версия X» с кнопками «Обновить» и «Позже» и строка в настройках. Ничего не качается без согласия.
- **Скачивание и проверка**: файл для своей платформы (AppImage / zip) и его подпись `<файл>.sig` (ed25519 над SHA-256 файла). Открытый ключ вшит в SLAM (`UPDATE_PUBLIC_KEY`); закрытый — секрет репозитория `SLAM_UPDATE_KEY`, им подписывает `release.yml`. Пока ключ не задан (константа-заглушка), обновления выключены. Файл без верной подписи отбрасывается.
- **Установка при перезапуске**: Linux — новый AppImage пишется рядом с запущенным (`$APPIMAGE`) и атомарно заменяет его; Windows — запущенный `slam.exe` переименовывается в `slam.exe.old`, файлы из zip встают на места, `.old` удаляется при следующем запуске. Затем SLAM перезапускается. Без AppImage (запуск из `cargo run`) установка недоступна, остаётся ссылка на выпуск.
- Сеть и запись файлов — только в фоновом потоке, не в update-тике. HTTP-клиент `ureq` с rustls, подпись `ed25519-dalek` (лицензии MIT/Apache и BSD-3, совместимы с GPL).

## Последствия
- Владелец проекта должен один раз создать ключ и положить закрытую часть в секреты GitHub, открытую — в код.
- В выпуске появляются файлы `.sig`.

## Отвергнутые варианты
- **Только SHA-256.** Защищает от порчи при загрузке, но не от подмены выпуска.
- **Ставить без вопроса.** Пользователь хочет решать сам.
