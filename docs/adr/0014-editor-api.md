# ADR-0014: API для внешнего редактора

- Статус: Принято
- Дата: 2026-10-08

## Решение
- Редактора в клиенте нет.
- `slam-formats`, `slam-osu`, `slam-skin` публикуются как библиотеки.
- JSON-RPC через named pipe / unix-сокет: тест-плей, горячая перезагрузка карты, управление воспроизведением, события попаданий, добавление в библиотеку. Версионируемый протокол, токен, только локально.
- Режим рабочей папки для существующих редакторов.

## Последствия
Ядро должно оставаться без зависимостей от движка (это и так принцип №1).
