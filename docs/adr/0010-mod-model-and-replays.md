# ADR-0010: Модель модов как в lazer, форматы реплеев

- Статус: Принято
- Дата: 2026-10-08

## Решение
- Мод = акроним + словарь настроек, как в lazer. Встроенные моды используют акронимы lazer.
- Реплеи SLAM пишутся в `.osr` с блоком lazer, если все моды — встроенные; иначе — контейнер SLAM (ID, версия, хеш, настройки модов, сид, сгенерированная карта при необходимости).
- Замена модов через DA (HR/EZ → DA) отменена.

## Последствия
- Блок модов лазерных реплеев читается без конвертации.
- Реплеи SLAM со встроенными модами открываются в lazer.
