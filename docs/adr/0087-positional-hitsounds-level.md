# ADR-0087: Уровень позиционных хитсаундов

- Статус: Принято
- Дата: 2026-11-04
- Дополняет [ADR-0039](0039-mixer-voice-control.md) и [ADR-0048](0048-live-settings.md) (не заменяет)

## Контекст
Баланс сэмплов геймплея по горизонтальной позиции объекта уже портирован (`slam_play::gameplay_sounds::sample_balance`): удар и хвост получают баланс в момент попадания, звук скольжения слайдера — каждый кадр по позиции шара. Уровень эффекта — константа `DEFAULT_POSITIONAL_LEVEL = 0.2`, игрок её поменять не может (#284).

Лазер (эталон `2026.1005.0-lazer`):
- `OsuSetting.PositionalHitsoundsLevel` — `float`, по умолчанию 0,2, диапазон 0–1, шаг 0,01;
- на экране настроек: Gameplay → Audio, подпись «Hitsound stereo separation», значение в процентах, при 0 — «Disabled»;
- `CalculateSamplePlaybackBalance(position) = round(level × 2 × (position − 0,5), 2)`; значение подхватывается сразу через bindable.

## Решение
- В `slam.toml` (секция `audio`) — `positional_hitsounds_level`: 0–1, округление до 0,01, по умолчанию 0,2. Значение вне диапазона заменяется значением по умолчанию с предупреждением, как у остальных чисел файла.
- На экране настроек (секция звука) — ползунок в процентах (0–100 %, шаг 1 %), при 0 — «Выключено».
- Уровень приходит в `SoundSettings::positional_level` при подготовке попытки и действует со следующей попытки, как остальные настройки игры (ADR-0048, ADR-0085). Формула и место пересчёта баланса не меняются.

## Последствия
- Разделение стерео можно настроить и сверить с лазером; судейство и реплеи от настройки не зависят.
- Изменение посреди попытки слышно только со следующей — отличие от лазера, где bindable действует сразу.

## Отвергнутые варианты
- **Применять на лету в текущей попытке** — пришлось бы протаскивать уровень в живую сессию ради настройки, которую меняют вне игры; остальные настройки игры тоже действуют со следующей попытки.
- **Секция `gameplay`** (в лазере подраздел Audio внутри Gameplay) — в SLAM звуковые настройки, в том числе задержка хитсаундов, живут в `audio`.
