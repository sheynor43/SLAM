# ADR-0007: Самостоятельная библиотека, снапшот, без скачивания карт

- Статус: Принято
- Дата: 2026-10-08

## Контекст
stable и lazer лагают в выборе песни. Клиент должен работать без других клиентов. Скачивание карт из клиента не нужно.

## Решение
- Файлы карт по SHA-256; SQLite — источник истины, доступ только из потока библиотеки.
- Снапшот `library.bin` (`rkyv`, mmap, данные по колонкам) для меню.
- Поиск и сортировка — в рабочем потоке по колонкам; виртуализированная карусель; миниатюры и бюджет загрузки текстур; фоновые звёзды с модами.
- Наполнение: `.osz`, опциональный импорт из stable (на месте) и lazer (экспортёр + хардлинки), режим рабочей папки.
- **В клиенте нет встроенного скачивания карт и связанных веб-интерфейсов.**

## Последствия
- Мгновенный старт меню и плавная прокрутка на больших библиотеках.
- Две структуры данных (SQLite и снапшот) нужно держать согласованными: снапшот пересобирается после каждой транзакции изменений.

## Отвергнутые варианты
- Запросы к базе из UI-потока: причина лагов в существующих клиентах.
- Хранение по хешам для скинов: неудобно для скинеров (скины — обычные папки, см. ADR-0008).
