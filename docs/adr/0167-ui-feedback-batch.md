# ADR-0167: Правки интерфейса по отзыву — блик, пульсация, превью с модами, шрифты, моды

- Статус: Принято
- Дата: 2026-11-26
- Заменяет блик выбранных кнопок из [ADR-0136](0136-ui-refresh-3.md) и жирный шрифт интерфейса по умолчанию; вращение курсора меню в простое (ADR-0136) по умолчанию выключено

## Контекст
Пользователь прислал список правок с примерами лазера (масштаб интерфейса 0.85) и stable: блик, скользящий почти по каждой кнопке, отвлекает; превью музыки не ускоряется с DT; звёзды мигают при смене скорости; плашка информации о карте прыгает; превью карт искажаются наклоном; шрифты слишком жирные, панель настроек слишком широкая; выбор модов мелкий и без множителей.

## Решение
- **Блик убран** со всех кнопок (шейдер больше не рисует полосу). Взамен в выборе песни выбранная плашка мягко **пульсирует свечением в такт** музыки (по таймингам карты: удар на каждой доле, сильнее на первой доле такта и в kiai); при выключенных эффектах (ADR-0123) пульсации нет.
- **Превью музыки с модами скорости**: DT/HT меняют темп с сохранением высоты, NC/DC — частоту (с высотой), как моды в игре. Смена модов применяется сразу.
- **Звёзды при смене модов**: список показывает прежние значения, пока не придут новые (не откатывается к звёздам без модов).
- **Превью карты в наклонной плашке**: плашка обрезает картинку наклонными краями, сама картинка не сдвигается (UV по прямоугольнику, маска по форме).
- **Плашка информации о карте**: ширина по самому длинному тексту (в пределах наибольшей ширины), меняется плавно; содержимое не перескакивает.
- **Шрифты**: обычный текст — вес 500 вместо 700, подписи — 500 вместо 600; жирный остаётся у заголовков. Панель настроек уже (как у лазера при 0.85).
- **Выбор модов**: плитки крупнее; при открытии столбцы выезжают поочерёдно снизу и сверху; в шапке — множитель счёта набора, у плитки — множитель мода; в локальных рекордах рядом с модами — множитель.
- **Курсор меню**: тёмный вариант, скругленнее; вращение в простое по умолчанию выключено.
- **Поиск** (выбор песни и настройки): кроме другой раскладки, подписи настроек ищутся на обоих языках интерфейса; Ctrl+Backspace стирает слово; печать и стирание — с анимацией и звуком.

## Последствия
- Темы со своим `button_sheen` больше не дают блика (ключ читается и игнорируется).
- Пульсации нужен текущий такт карты в выборе песни.

## Отвергнутые варианты
- **Оставить блик с выключателем.** Пользователь просит убрать совсем; выключателей и так много.
- **Скрывать звёзды до пересчёта.** Список мигал бы так же.
