# ADR-0126: Стили переходов между экранами: нет, простые, сложные

- Статус: Принято
- Дата: 2026-11-14
- Дополняет [ADR-0044](0044-screen-stack.md) (поза слоя и длительность) и [ADR-0123](0123-interface-effects.md)

## Контекст
Переход между экранами один: 200 мс, проявление со сдвигом на 0,1 ширины, ease-out (ADR-0044). Правила интерфейса разрешали только fade/slide. Пользователь хочет выбирать переходы: без них, простые или сложные (#364, часть 2).

## Решение
- **Настройка** `general.transitions`: `none`, `simple`, `fancy`; по умолчанию `simple`. Меняется на лету; переход, идущий в момент смены, доигрывается в прежнем стиле.
- **`none`:** смена экрана мгновенная, уходящий слой не рисуется.
- **`simple`:** нынешний переход ADR-0044 без изменений.
- **`fancy`:** 450 мс, quint ease-out. Поза слоя получает масштаб вокруг центра: входящий экран проявляется из 1,06 в 1,0 со сдвигом 0,15 ширины, уходящий уменьшается до 0,94 и гаснет. Поверх слоёв через экран проходит скошенная полоса цвета акцента (скос — `Theme::button_skew()`, фигура ADR-0116): при push — справа налево, при pop — слева направо; её прозрачность пиковая в середине перехода. Без `general.effects` полоса не рисуется, масштаб и сдвиг остаются.
- **Поза** (`Pose`) становится `{ opacity, offset, scale }`; длительность и кривая берутся из стиля; все константы — токены темы. Поза остаётся чистой функцией времени и стиля.
- **Ввод** по-прежнему сразу верхнему экрану; попадание — по раскладке в покое.
- Правило интерфейса «только fade/slide» заменяется: переходы — по стилю этого ADR.

## Последствия
- В `fancy` два слоя дольше рисуются вместе: 450 мс вместо 200.
- Масштаб слоя применяется к фигурам, спрайтам и тексту слоя через матрицу слоя draw.

## Отвергнутые варианты
- **Переход как у лазера по каждому экрану.** У лазера у каждого экрана свой переход (логотип, параллакс, фон); повторять — много кода ради мелочей, вид не наш.
- **Сложный переход через рендер-таргет и шейдер (растворение, размытие).** Два полноэкранных таргета на переход; полоса и масштаб дают заметный эффект без них.
