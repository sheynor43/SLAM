# ADR-0011: Локализация на Fluent, языковые пакеты

- Статус: Принято
- Дата: 2026-10-08

## Решение
- Fluent (`.ftl`), все строки интерфейса через ключи с первого дня.
- Языковой пакет `.slamlang`: `manifest.toml` + `.ftl`; фолбэк на английский; горячая перезагрузка.
- Плагины приносят свои переводы в своём пространстве имён.
- `slam i18n check` — отчёт о недостающих и устаревших ключах, в CI.

## Отвергнутые варианты
JSON-словари как в Minecraft: нет нормальной поддержки множественных форм.
