# ADR-0130: Пропорции выбора песни по лазеру; скос — настройка

- Статус: Принято
- Дата: 2026-11-14
- Уточняет [ADR-0117](0117-colour-schemes.md) (скос из токена становится настройкой) и [ADR-0121](0121-song-list-lean-and-smooth-scroll.md)

## Контекст
Выбор песни выглядит слишком крупным. Пользователь дал снимок выбора песни лазера при 1920×1080 и хочет такие же размеры списка, названия и характеристик, со скосами, а скос — настраиваемым. Плашка под списком карт лишняя: под списком должен быть виден фон.

## Решение
- **Пропорции при 1920×1080 и масштабе меню 1,0** (дальше — пропорционально высоте окна и `general.menu_scale`): список карт справа шириной ~38 % окна, строка сета ~90 px, название ~28 px, исполнитель ~18 px, строка сложности ниже строки сета; левая плашка — название ~36 px, исполнитель ~20 px, характеристики ~16 px, полоски по высоте как у лазера. Точные значения — токены темы, снятые со снимка лазера.
- **Под списком нет плашки**: строки лежат прямо на фоне (с затемнением фона). Строки, поиск и левая плашка остаются фигурами со скосом.
- **Скос — настройка** `general.skew` (0–20°, по умолчанию 10°, шаг 1°), раздел «Интерфейс». Меняется на лету: `Theme::button_skew()` берёт значение настройки, раскладки и попадание мышью — из него.

## Последствия
- Больше строк на экране; миниатюры (ADR-0127) — по высоте строки.

## Отвергнутые варианты
- **Скос только в `theme.toml`.** Редактора темы ещё нет.
