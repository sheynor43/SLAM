# ADR-0172: Список песен по дуге, плавные позиции строк, фон при удержании выбора

- Статус: Принято
- Дата: 2026-11-27
- Заменяет наклон списка из [ADR-0121](0121-song-list-lean-and-smooth-scroll.md) (ряды ниже — левее); сдвиги невыбранных строк (ADR-0149) в силе

## Контекст
Пользователь сравнил выбор песни с лазером: в лазере плашки стоят по дуге (средняя — левее, к краям — правее) и уходят за правый край окна; у нас список наклонён по скосу кнопок, справа у плашек пустое место. При быстром листании в списке появляются дыры (закрывающиеся сеты оставляют пустое место, строки скачут), а фон отстаёт: пока выбор меняется чаще 150 мс, фон не меняется вовсе.

## Решение
- **Дуга лазера** (`Carousel.offsetX`): строка с центром на высоте `y` сдвигается вправо на `(3 − √(9 − d²)) · h`, где `h` — половина высоты списка, `d = |y − середина| / h`; умножается на настройку `song_select.curve` (0..=2, по умолчанию 1; 0 — прямой столбец). Наклон списка убран (`lean = 0`), попадание мышью — по дуге.
- **Плашки до края окна и дальше**: плашка рисуется до правого края окна с запасом на скругление, тексты, звёзды и pp остаются в пределах списка.
- **Плавные позиции строк**: у каждой видимой строки (по ключу сета или сложности) своя позиция, догоняющая место в списке с полупериодом 50 мс (`DampContinuously` лазера); новая сложность выезжает из-под своего сета, строка, которой не было в прошлом кадре, сразу на месте. Таблица фиксированного размера, без аллокаций. Расширение сета (ADR-0136) теперь даёт только проявление сложностей.
- **Фон при удержании выбора**: кроме 150 мс покоя, фон подгружается и тогда, когда с прошлой загрузки прошло 400 мс, — при зажатой стрелке он идёт за выбором, а не стоит на старом.

## Последствия
- Попадание мышью во время движения строк считается по их местам, не по рисуемым позициям (как раньше).
- Высота списка определяет силу дуги; на очень низких окнах дуга слабее.

## Отвергнутые варианты
- **Оставить наклон и добавить дугу поверх.** Двойное смещение, пользователь просил как в лазере.
- **Убирать дыры ускорением анимации расширения.** Дыры остаются, только короче.
