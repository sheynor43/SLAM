# ADR-0067: Характеристики выбранной карты на выборе песни

- Статус: Принято
- Дата: 2026-10-25

## Контекст
Тестеру альфы на выборе песни нужны характеристики выбранной сложности: длина, BPM, число объектов, CS/AR/OD/HP с модами. В лазере их показывает `BeatmapTitleWedge`: длина `BeatmapInfo.Length / rate` (`mm:ss`), BPM `min-max (mostly X)` с учётом скорости, счётчики объектов из `GetStatistics`, сложность через `GetAdjustedDisplayDifficulty` (моды, затем AR и OD через preempt и окно 300 с делением на скорость). Длину и BPM лазер сохраняет при импорте. У нас хранилища нет до M4, а скан читает только заголовки (`headers_only`, ADR-0066): объекты и тайминг при скане не разбираются. Звёзд нет: `rosu-pp` ещё не подключён.

## Решение
- **Расчёт в `slam-osu`.** Модуль `statistics`: `BeatmapStatistics::of` (длина и длина без перерывов, BPM минимальный, максимальный и самый частый, круги, слайдеры, спиннеры), `round_bpm` и `adjusted_display_difficulty`. Формулы портированы из лазера дословно.
- **Когда считается.** Длина, BPM и счётчики считаются в потоке библиотеки полным разбором `.osu` выбранной сложности, когда выделение 150 мс стоит на одной сложности (как фон, ADR-0066). Запрос и ответ идут по своим кольцам; ответ — `Copy`-структура. Update показывает ответ только для сложности, выделенной сейчас: при переходе на другую строка статистики пуста до нового ответа.
- **Что считается в update.** CS/AR/OD/HP с модами — сразу из значений библиотеки, без ожидания. Скорость модов применяется к длине и BPM тоже в update: смена модов не перезапрашивает файл.
- **Отображение.** Вверху панели, над строкой поиска, две строки текста: «длина · BPM · круги · слайдеры · спиннеры» и «CS · AR · OD · HP». Подписи — ключи Fluent; значения сложности — до двух знаков после запятой без лишних нулей (`0.##`, как в лазере). BPM — одним числом или `min-max (X)`. Отдельной строки статуса больше нет: пока список не готов (нет папки, скан, ошибка, загрузка), статус показывается на месте первой строки.
- **Пока не делаем:** звёзды, подсказку с длиной без перерывов, цвет значений, изменённых модами.

## Последствия
- Характеристики видны без хранилища; повторный выбор той же сложности снова разбирает файл (миллисекунды на потоке библиотеки).
- Список строк сдвигается вниз на высоту строки текста (строка статуса стала первой строкой характеристик). Во время скана длина и BPM не видны: их место занимает статус.
- После M4 длина, BPM и счётчики переедут в хранилище (считаются при импорте), запрос на выбор уйдёт.

## Отвергнутые варианты
- **Полный разбор при скане.** Скан библиотеки stable в тысячи карт станет в разы дольше ради чисел, которые смотрят у одной карты.
- **Считать в update.** Разбор файла — I/O и аллокации на горячем пути.
