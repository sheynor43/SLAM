# ADR-0188: Тур по экранам для скриншотов README

- Статус: Принято
- Дата: 2026-11-28

## Контекст
README нужны настоящие скриншоты игры: с библиотекой карт, скином, музыкой и визуализатором, а не превью `ui-preview` с образцами данных. Снимать их вручную долго и каждый раз по-разному.

## Решение
- Переменная окружения `SLAM_TOUR=<папка>` включает тур: обычная игра запускается как всегда, а поток update по сценарию (`crate::tour::SCRIPT`, мс от первого тика) нажимает клавиши, выбирает Autoplay и просит кадры; в конце игра закрывается.
- Кадр читается потоком draw перед `present` (`Backend::read_frame`, сейчас только OpenGL), PNG пишет отдельный поток.
- Это инструмент разработчика: без переменной ничего не меняется; с ней тур выделяет память и пишет файлы — на горячих путях обычной игры этого нет.
- Картинки README лежат в `docs/images/` (JPEG 1600 px, логотип PNG).

## Последствия
- Скриншоты обновляются одним запуском; сценарий правится в `tour.rs`.
- На скриншотах фоны карт из библиотеки снимающего.

## Отвергнутые варианты
- **Превью `ui-preview`** — образцы данных, без фона карт и музыки.
- **Внешняя автоматизация окна (xdotool)** — привязана к X11 и окружению.
