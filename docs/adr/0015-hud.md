# ADR-0015: HUD — минимальный набор и редактор раскладки

- Статус: Принято
- Дата: 2026-10-08

## Решение
- По одному компоненту каждого вида, стиль — настройка (без дублей вариантов Argon/Triangles/Legacy).
- Набор: счёт, точность, комбо, здоровье, прогресс, индикатор ошибок, pp, UR, клавиши, CPS, счётчик попаданий, моды, лидерборд, текст с шаблоном.
- Текст с шаблоном заменяет старрейт, атрибуты карты, имя игрока и произвольный текст.
- Редактор раскладки: привязки, масштаб, поворот, прозрачность, свойства компонента (шрифт, цвет и т.д.); превью на автоплее или реплее.
- Импорт HUD JSON лазера через таблицу соответствия.
- Компоненты UI-модулей размещаются тем же редактором.
