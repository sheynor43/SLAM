# ADR-0003: Свой HAL рендера, OpenGL 3.3 первым, naga

- Статус: Принято
- Дата: 2026-10-08

## Контекст
Бюджет кадра при 8000 FPS — 125 мкс. Рендер простой: спрайты, меши слайдеров, MSDF-текст, рендер-таргеты. Нужно оставить возможность для macOS.

## Решение
- Тонкий собственный HAL с небольшой поверхностью API.
- Бэкенды: OpenGL 3.3 (первый, фолбэк) → D3D11 (Windows, по бенчмарку) → Vulkan (опционально) → Metal (macOS позже).
- Шейдеры пишутся один раз, транслируются через `naga`.

## Последствия
- OpenGL быстро запускается и работает везде.
- Известные ограничения OpenGL учитываются: на Windows в окне/borderless возможна лишняя задержка из-за композитора; загрузка текстур из рабочих потоков неудобна (решается staging-буферами и загрузкой в draw-потоке с бюджетом).
- Добавление Metal не требует переписывать шейдеры.

## Отвергнутые варианты
- wgpu: удобен, но универсальность стоит процессорного времени; остаётся запасным вариантом, если свой HAL окажется слишком дорогим в поддержке.
- Только OpenGL: проблемы с задержкой на Windows и будущее на macOS.
