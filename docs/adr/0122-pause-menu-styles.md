# ADR-0122: Стили меню паузы и провала и их отдельный масштаб

- Статус: Принято
- Дата: 2026-11-14
- Уточняет ADR-0118 (масштаб в игре), ADR-0052 (меню паузы и провала)

## Контекст
Меню паузы и провала портированы с лазера (ADR-0052) и не похожи на обновлённый интерфейс (ADR-0116, ADR-0117). Пользователь хочет выбирать стиль меню и отдельный масштаб для него, а не общий с HUD (#364).

## Решение
- **Настройка** `gameplay.pause_menu_style`: `slam` (по умолчанию), `lazer`, `stable`.
  - `slam` — скошенные скруглённые кнопки с узором и обводкой выбранной, плашка под заголовком и информацией, цвета схемы (ADR-0117); раскладка и ввод — как у лазера (те же кнопки, порядок, клавиши и выбор), меняется только вид.
  - `lazer` — нынешнее меню (ADR-0052) без изменений.
  - `stable` — изображения скина: `pause-overlay` / `fail-background` в размере stable (высота окна / 768, по центру: 1366×768 закрывает окно 16:9, картинка меньше остаётся в середине; McOsu растягивает фон на всё окно, отчего маленькие фоны раздуваются за края); затемнение под меню чёрное, 85 % (stable уводит игру почти в чёрный; серое затемнение McOsu 0,078 при 0,58 оставляет игру серой) и кнопки `pause-continue`, `pause-retry`, `pause-back` в раскладке stable (по McOsu, ADR-0107), попадание мышью — по их рамкам; нет всех трёх кнопок в скине — меню SLAM.
- **Масштаб.** `gameplay.pause_menu_scale` (0,75–1,5, по умолчанию 1) — только меню паузы и провала. `general.game_scale` из ADR-0118 теперь масштабирует только HUD (вместе с кнопкой пропуска).
- Стиль и масштаб меняются на лету, в том числе при открытой паузе: попадание мышью и отрисовка берут их из одного снапшота меню.

## Последствия
- Попадание мышью в стиле `stable` — по прямоугольникам изображений скина, в остальных — по раскладке лазера.
- Изображения скина для `stable` загружаются вместе с текстурами игры.

## Отвергнутые варианты
- Один стиль SLAM: пользователи stable узнают своё меню паузы из скина.
- Общий масштаб с HUD: меню паузы читают с другого расстояния внимания, чем HUD.
