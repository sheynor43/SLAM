# ADR-0012: Лицензия MIT OR Apache-2.0

- Статус: Принято
- Дата: 2026-10-08

## Решение
- Код — `MIT OR Apache-2.0`: обязательное указание автора, разрешено коммерческое использование.
- Дефолтный скин — CC-BY-NC 4.0 (osu-resources), в отдельной папке со своей лицензией; README предупреждает, что коммерческим форкам нужно заменить скин.
- Портированный код lazer — с уведомлением MIT в `THIRD_PARTY_NOTICES`.
- GPL- и LGPL-зависимости запрещены (`cargo deny`).
- Бренд «osu!» не используется в названии и оформлении.

## Отвергнутые варианты
PolyForm Noncommercial: проект перестаёт быть open source, больше сложностей с распространением.
