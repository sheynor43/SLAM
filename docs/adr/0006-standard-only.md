# ADR-0006: Только osu!standard

- Статус: Принято
- Дата: 2026-10-08

## Решение
Поддерживается только режим osu!standard. Абстракции «рулсетов» нет; крейт `slam-osu` — конкретная реализация.

## Последствия
Меньше кода и косвенных вызовов. Если понадобится другой режим — отдельный крейт, без переделки существующего.

## Отвергнутые варианты
Общая абстракция рулсетов как в lazer: преждевременное обобщение.
