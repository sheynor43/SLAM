# ADR-0169: Импорт файлов перетаскиванием

- Статус: Принято
- Дата: 2026-11-26

## Контекст
Новую карту приходится распаковывать в `Songs` вручную, а затем перезапускать игру. Пользователь хочет перетаскивать файлы в окно, как в stable. Своей базы карт пока нет (ADR-0007), библиотека — папка `Songs` stable.

## Решение
- Окно принимает перетаскивание файлов (SDL `DROP_FILE`) на любом экране, кроме игры.
- **Карты** `.osz` (stable) и `.olz` (лазер) распаковываются в `Songs` в папку с именем архива (при совпадении — с суффиксом), через `slam-formats::archive` (ADR-0030); затем библиотека пересканируется.
- **Скины** `.osk` — в `Skins` рядом с `Songs`, затем обновляется список скинов.
- **Реплеи** `.osr` — копируются в папку реплеев SLAM (просмотра реплеев пока нет).
- После успешного импорта исходный архив **удаляется** (как в stable); при ошибке остаётся. Итог — уведомлением.
- Импорт идёт в фоновом потоке, не в update-тике.
- **F5** в выборе песни пересканирует библиотеку.

## Последствия
- Распаковка в `Songs` — временное решение до своей базы карт.
- Удаление архива необратимо; удаляется только файл, импорт которого удался.

## Отвергнутые варианты
- **Оставлять архив.** Пользователь просит удалять, как stable.
