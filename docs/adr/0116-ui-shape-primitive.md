# ADR-0116: Примитив фигур интерфейса — скруглённый скошенный прямоугольник с узором

- Статус: Принято
- Дата: 2026-11-14

## Контекст
Интерфейс черновой: кнопки и плашки — прямоугольники из белого пикселя атласа с тинтом (ADR-0020), других примитивов, кроме кольца (`push_ring`) и MSDF-текста, нет. Нужны скругления, наклон (скос) кнопок и плашек, полупрозрачность и мелкий узор внутри (как треугольники на кнопках лазера) — #364.

Ограничения: вершина спрайта фиксирована (32 байта) и общая для геймплея; кадр без аллокаций; каждый слой экрана рисуется как «фигуры, затем текст» (ADR-0044), порядок внутри слоя сохраняется.

## Решение
- **Отдельный батч и шейдер для интерфейса:** `slam-render::shape::ShapeBatch` и `shaders/ui_shape.wgsl`. Вершина — 64 байта: позиция, цвет (sRGB, прямая альфа, ADR-0020), UV, локальная точка в пикселях фигуры, полуразмеры, радиус скругления, толщина обводки (0 — заливка), сила узора, фаза узора.
- **Форма — SDF скруглённого прямоугольника** в локальных (нескошенных) координатах, сглаживание края — `fwidth`. **Скос** задаётся геометрией: вершины квада сдвигаются по x на `tan(угол) × y`, а локальные координаты не меняются, поэтому скошенная фигура — сдвиг скруглённой, без искажения радиуса по горизонтали.
- **Текстура:** фигура умножает цвет на выборку текстуры по UV (атлас — белый пиксель для сплошной заливки, регион фона или миниатюры карты), так картинка обрезается по скруглённой форме без масок.
- **Узор:** процедурный в шейдере — сетка треугольников разной яркости по локальным координатам, сдвиг по времени из uniform-буфера (время интерфейса, не геймплея). Сила 0 — без узора, вычисление пропускается ветвлением по вершинному значению.
- **Место в кадре:** экраны рисуют плашки, кнопки и строки в `ShapeBatch` вместо `SpriteBatch`; слой — фигуры, затем текст, как сейчас. Батчи режутся по текстуре и смешиванию, как у спрайтов; запись без аллокаций после разогрева.
- Геймплей и HUD скина остаются на спрайтах.

## Последствия
- Скругления, скос, обводки, полупрозрачность и узор — одним проходом, без рендер-таргетов и масок.
- Ещё один конвейер и кольцо буферов на бэкенд (GL и D3D11); шейдер транслируется `naga`, как остальные.
- Внутри одной фигуры нельзя смешать два узора или две текстуры — рисуются две фигуры.
- Миниатюры и фон, обрезанные по скруглению, получаются бесплатно.

## Отвергнутые варианты
- Расширить вершину спрайта: +32 байта на каждый спрайт геймплея ради интерфейса.
- Девятислайсовые текстуры скруглений: скос и радиус меняются с масштабом, текстур пришлось бы много.
- Маски через трафарет/рендер-таргет: дороже и рвёт батчи.
