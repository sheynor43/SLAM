# ADR-0128: Вид курсора SLAM по образцу лазера

- Статус: Принято
- Дата: 2026-11-14
- Уточняет [ADR-0124](0124-cursor-styles.md) в части вида курсора SLAM; настройки и режимы не меняются

## Контекст
Скруглённая стрелка ADR-0124 пользователю не понравилась: нужен курсор «как в лазере». Настройки курсора пользователь не нашёл в экране настроек.

## Решение
- **Курсор меню** — по пропорциям и поведению курсора меню лазера (`MenuCursor`), но нарисованный кодом примитивом фигур, без ассетов лазера: заострённый указатель, наклонённый влево, белая заливка, тонкая тёмная обводка для читаемости на светлом фоне, мягкое свечение цвета акцента (только с `general.effects`). При нажатии сжимается до ~0,9 и возвращается с упругой кривой, при перетаскивании правой кнопкой поворачивается к направлению движения, как в лазере; при отпускании возвращается. Размеры, длительности и кривые — токены темы, сверенные с `MenuCursor` лазера.
- **Курсор SLAM в игре** — как курсор лазера по умолчанию (`OsuCursor` без скина): круг с белой обводкой и заливкой цвета акцента, внутренний светлый круг; расширяется при нажатии по тем же `CursorExpand`-временам, что и курсор скина (`ExpandTimes`). След скина сохраняется.
- **Настройки курсора** (`general.menu_cursor`, `gameplay.cursor_style`, размер, авторазмер, след) переезжают в новый раздел настроек «Скин» ([ADR-0133](0133-settings-continuous-list.md)); имена ключей в `slam.toml` не меняются.

## Последствия
- Курсор меню остаётся ~10 фигурами на кадр, без текстур.
- Поворот при перетаскивании требует позиции и кнопок указателя в потоке draw — уже есть в `PointerWatch`.

## Отвергнутые варианты
- **Текстура курсора лазера.** Ассеты лазера не распространяются с SLAM.
