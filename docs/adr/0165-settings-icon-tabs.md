# ADR-0165: Вкладки настроек — значки одного цвета

- Статус: Принято
- Дата: 2026-11-21
- Заменяет разноцветные вкладки разделов настроек из [ADR-0136](0136-ui-refresh-3.md) (каждый раздел — свой оттенок); остальное в ADR-0136 в силе

## Контекст
Боковая панель настроек (ADR-0095, ADR-0133) — широкие плашки с названиями разделов («Звук», «Скин», «Игра» и т. д.), каждая своим цветом оттенка (ADR-0136). Пользователь считает их слишком крупными и пёстрыми: панель настроек выходит широкой.

## Решение
- **Вкладка — квадратная кнопка со значком** вместо плашки с названием. Значки рисуются фигурами (`ShapeBatch`): своего иконочного шрифта в SLAM нет (как шевроны кнопки пропуска, ADR-0160). По значку на раздел: звук, смещение, клавиши, экран, скин, частоты, игра, библиотека, связь.
- **Один цвет у всех вкладок**: обычная заливка кнопки из темы; текущий раздел подсвечен акцентом схемы (ADR-0117), наведение — как у остальных кнопок. Оттенки разделов (`section_tints`) больше не используются вкладками.
- **Название раздела** показывается подсказкой у вкладки при наведении и остаётся заголовком раздела в списке; поиск по названиям разделов (ADR-0095) работает как прежде.
- Ширина колонки вкладок — по ширине значка; освободившееся место отдаётся списку строк, а панель целиком становится уже.

## Последствия
- Панель настроек уже, а боковая колонка спокойнее; без подсказки раздел узнаётся по значку и по заголовку в списке.
- Новые разделы требуют своего значка.

## Отвергнутые варианты
- **Подписи мельче без значков.** Колонка остаётся широкой из-за самых длинных названий («Библиотека»).
- **Значки шрифтом.** Нужен иконочный шрифт и его лицензия; фигур хватает.
