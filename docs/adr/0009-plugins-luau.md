# ADR-0009: Плагины на Luau, генеративные моды

- Статус: Принято
- Дата: 2026-10-08

## Контекст
Пользователи должны писать моды «одним файлом», устанавливать их безопасно; нужны UI-модули и коннекторы к серверам.

## Решение
- Luau через `mlua`: песочница, лимиты памяти и инструкций, по VM на плагин.
- Типы: `gameplay_mod`, `ui_module`, `connector`. Права в манифесте, подтверждение пользователем.
- Геймплейные моды имеют **полный контроль над картой** при загрузке (генеративные моды), с валидацией результата хостом.
- Основной путь визуальных модов — декларативные анимации, вычисляемые движком.
- Встроенные моды реализуют тот же трейт `GameplayMod` нативно.
- Документация и типы для luau-lsp генерируются из описания API в Rust.

## Последствия
- Реплеи с кастомными модами — контейнер SLAM со вложенной сгенерированной картой.
- Сравнимость скоров со сгенерированными картами решают серверы; балансировка — позже.
- Нужно поддерживать стабильность и версионирование API.

## Отвергнутые варианты
- WASM: безопаснее и быстрее, но требует компиляции; возможен как второй бэкенд позже.
- Rhai: медленнее, меньше инструментов.
- Ограниченный доступ к карте: исключает генеративные моды.
