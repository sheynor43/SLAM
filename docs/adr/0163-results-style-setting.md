# ADR-0163: Настройка вида экрана результатов

- Статус: Принято
- Дата: 2026-11-21
- Заменяет пункт «Когда» [ADR-0158](0158-stable-ranking-screen.md) (остальное в силе)

## Контекст
По ADR-0158 экран результатов рисуется в виде stable, если в цепочке скина меню есть `ranking-panel`, а отдельной настройки нет. Пользователь искал в настройках, где переключить вид результатов, и не нашёл: со скином stable экран SLAM не получить, не сменив скин.

## Решение
- **Настройка `general.results_style`**, значения `skin` и `slam`, по умолчанию `skin`.
  - `skin` — как раньше: вид stable, если в скине меню есть `ranking-panel`, иначе экран SLAM.
  - `slam` — всегда экран SLAM.
- На экране настроек — строка с выбором рядом с другими настройками вида интерфейса; строки — ключи Fluent (en и ru). Меняется на лету: открытый экран результатов перестраивается со следующего тика, как при смене скина.
- Неизвестное значение в `slam.toml` — предупреждение в лог и значение по умолчанию, как у других перечислений.

## Последствия
- Картинки результатов stable при `slam` не нужны: поток их загрузки может их не держать, но и держать их не ошибка (экран просто их не использует).
- Если появятся другие виды (например лазера), они добавятся новыми значениями той же настройки.

## Отвергнутые варианты
- **Только автоматический выбор по скину (ADR-0158).** Без смены скина экран SLAM не получить.
- **Флажок «вид stable» вкл/выкл.** Перечисление расширяется без миграции настройки.
