# ADR-0151: Звёзды и максимальные pp с модами в строке сложности

- Статус: Принят
- Дата: 2026-11-16
- Дополняет ADR-0134 и ADR-0135 (звёзды без модов, поток звёзд)

## Контекст
В строке сложности много пустого места, а звёзды в ней — без модов (ADR-0134). Игроку нужно видеть, сколько звёзд и pp даст карта с выбранными модами (#384). pp в SLAM пока не считаются вовсе.

## Решение
- **Что показывать** — настройка `song_select.difficulty_info`: `stars` (по умолчанию, как было), `pp`, `stars_and_pp`. Строка-список в разделе выбора песни.
- **Что считается.** `rosu-pp` считает за один разбор файла звёзды и pp за SS (точность 100 %, полное комбо) — по формуле лазера (`lazer = true`). pp из уже посчитанных атрибутов сложности почти ничего не стоят, поэтому без модов звёзды и pp идут вместе.
- **Кеш на диске** `cache/stars.bin` хранит пару «звёзды, pp» без модов (формат 2; кеш формата 1 сбрасывается и считается заново).
- **Моды для расчёта** — компактный `RatingMods` (`Copy`, сравнивается по ключу из битов): биты stable, которые меняют звёзды или pp (`ModSet::to_legacy` под маской), флаги модов и настроек без бита stable (Classic и его «без точности головы слайдера», Traceable, Hidden только с кругами приближения), скорость (`true_gameplay_rate`) и значения Difficulty Adjust. В `rosu-pp` уходят как моды лазера с этими настройками, явная скорость и CS/AR/OD/HP с учётом модов. Прочие настройки (Mirror и т. п.) на звёзды и pp не влияют и не передаются.
- **Передача модов** в поток звёзд — через атомики `StarFocus` под счётчиком версии: update-поток раз в тик кладёт `RatingMods`, если он изменился. Без аллокаций и блокировок.
- **Расчёт с модами** — только для видимых сетов и нескольких после них, в первую очередь, до продолжения расчёта без модов. Значения — в кеше в памяти по ключу «файл, моды», ограниченном по размеру (переполнение — очистка целиком). Пачка с модами помечена их ключом; поток библиотеки отбрасывает пачки для других модов.
- **Показ.** Если моды не выбраны — значения без модов. С модами строка и левая плашка показывают значения с модами, а пока их нет — значения без модов (как устаревшее значение в лазере, до прихода нового). Порядок сложностей — по звёздам без модов, как раньше.
- pp — текст `"412pp"` (целые, суффикс — ключ Fluent `song-select-pp-suffix`) слева от плашки звёзд.

## Последствия
- Смена модов пересчитывает только видимое — на большой библиотеке это доли секунды на сет.
- Значения с модами при прокрутке появляются с задержкой расчёта.
- Профиль stable (ADR-0150) позже сменит формулу pp на stable (`lazer = false`) — поле в `RatingMods`.

## Отвергнутые варианты
- **Пересчёт всей библиотеки при смене модов.** Минуты работы на каждое нажатие.
- **Канал команд для модов.** `Sender::send` может аллоцировать в тике.
- **Хранить на диске значения с модами.** Комбинаций модов много, польза мала.
