# ADR-0177: Выбор песни — плавающие настройки модов, строка поиска под панелью, доска результатов, мягкий курсор

- Статус: Принято
- Дата: 2026-11-27
- Дополняет [ADR-0175](0175-song-select-footer.md) (размеры вокруг панели), заменяет закреплённую справа панель настроек модов ([ADR-0057](0057-mod-settings-panel.md): «Customise» с раскрытием при наведении) и мигание курсора из [ADR-0173](0173-settings-text-icons-scrollbar.md) (500 мс «горит», 530 мс «мигает» по жёсткому включению)

## Контекст
Пользователь сравнил выбор песни с osu!lazer при масштабе 0.85: выбор модов налезал на подсказку и верхнюю панель; закреплённая справа панель настроек закрывала колонки; над строкой поиска пустое место (в лазере поиск сразу под панелью инструментов); у доски локальных результатов лишняя пустота слева и она «прыгала» по высоте; курсор в полях был резким и горел даже в пустом поле.

## Решение
- **Настройки мода — плавающая панель.** Открывается правым кликом по плитке мода (у курсора; мод без настроек ничего не делает, невыбранный мод выбирается) или Tab (у курсора, без курсора — наверху справа). Заголовок панели тянется мышью; положение не сохраняется, при каждом открытии панель встаёт заново у курсора и всегда целиком в окне над нижней панелью. Закрывается Esc, нажатием вне панели и повторным правым кликом. Закреплённая панель с заголовком «Customise», раскрытие при наведении и сворачивание по таймеру убраны (состояние `ExpandedByMod` тоже: настройки мода, которому они нужны, открываются у курсора). Панель рисуется отдельным слоем поверх колонок, тексты колонок не просвечивают.
- **Выбор модов над нижней панелью**: затемнение, колонки и подсказка кончаются над нижней панелью; заголовок стоит под верхней панелью (ADR-0168). Нижняя панель остаётся доступной.
- **Строка поиска сразу под верхней панелью** (`song_top_gap`, 5 px, как в лазере); строка состояния (сканирование, нет папки) стоит на месте плейсхолдера. Список и панель информации поднялись выше. Подсказка клавиш внизу экрана убрана (ADR-0175); сообщение «нет аудиовыхода» стоит над нижней панелью.
- **Доска локальных результатов**: колонка ранга — 40 px (`song_score_rank_width`, как метка ранга лазера) вместо 44, ранг по центру колонки; высота доски плавно меняется 300 мс OutQuint (`song_board_ms`) при смене числа строк, строки проявляются как раньше.
- **Курсор ввода мягче**: полупрозрачный (0.6), тоньше, мигает плавными переходами 150 мс (`caret_fade_ms`) вместо резкого включения; виден только в используемом поле: с текстом в поле, либо пока с последнего изменения прошло меньше 3 с (`caret_active_ms`). Пустое поле поиска без недавнего ввода курсора не показывает. Поле ввода значения (клик по числу) всегда «используется». Первый введённый символ пустого поля считается изменением.
- **Пресеты модов** сохраняются строками `HD DT(speed_change=1.3)`: акронимы через пробел, настройки не по умолчанию в скобках `ключ=значение`; незнакомое при чтении отбрасывается, повторы тоже.

## Последствия
- Подсказка в выборе модов теперь про правый клик; Tab остаётся как клавиатурный путь.
- Окно уже ~1000 px показывает меньше пресетов на панели (не влезающие скрыты, но сохранены).
- Тесты ожидали заголовок и строку поиска в разных строках; теперь `header == search`.

## Отвергнутые варианты
- **Оставить закреплённую панель и добавить правый клик.** Пользователь просил убрать закреплённую панель.
- **Запоминать положение плавающей панели.** Пользователь просил сброс при каждом открытии.
- **Отдельная строка под строку состояния над поиском.** Пустое место над поиском — то, на что жаловался пользователь.
