# ADR-0132: Параллакс в меню

- Статус: Принято
- Дата: 2026-11-14
- Уточняет ARCHITECTURE §12 и [ADR-0123](0123-interface-effects.md)

## Контекст
Пользователь хочет параллакс с настройкой и выключением.

## Решение
- **Настройка** `general.parallax`: сила 0–100 % (0 — выключен), по умолчанию 100 %. Без `general.effects` параллакса нет.
- **Как в лазере** (`ParallaxContainer`, порт с пометкой): фон меню и выбора песни сдвигается против указателя на долю ~2 % размера экрана при силе 100 %, увеличен на столько же, чтобы не открывались края; слой интерфейса — слабее (~0,5 %). Сдвиг сглаживается экспонентой по времени кадра. В игре параллакса нет.
- Позиция указателя — из `PointerWatch` в потоке draw, без блокировок.

## Последствия
- Попадание мышью считается по раскладке без сдвига параллакса: расхождение до ~10 px у краёв при силе 100 %.

## Отвергнутые варианты
- **Параллакс по наклону окна или гироскопу.** Не нужно на ПК.
