# ADR-0013: Профили и файл настроек .slamcfg

- Статус: Принято
- Дата: 2026-10-08

## Решение
- Локальные профили: свои скоры, реплеи, настройки, профили скинов, раскладки.
- `.slamcfg` — архив для обмена настройками: `manifest.toml` + выбранные разделы (игровые настройки, клавиши, профиль скина ссылками или с файлами, раскладки HUD, тема, шрифты, список плагинов или сами плагины, язык).
- Секреты не экспортируются никогда; машинно-зависимые настройки — только вручную.
- Импорт: превью, выбор разделов, отчёт о недостающем, миграция схемы, подтверждение прав плагинов.
- Резервная копия профиля — отдельный формат, включает скоры и реплеи.
- Экспорт контента: `.osz`, `.osk`, `.osr`.

## Последствия
У настроек должна быть версионируемая схема с миграциями с самого начала.
