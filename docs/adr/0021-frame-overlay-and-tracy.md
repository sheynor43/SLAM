# ADR-0021: Оверлей фреймтайма как инструмент разработчика, Tracy за фичей

- Статус: Принято
- Дата: 2026-10-09

## Контекст
Для #8 нужен встроенный оверлей фреймтайма: график, перцентили p50/p99/p99.9 и частоты потоков draw, update и input (опрос главного потока). Есть два ограничения:
- По ADR-0011 весь текст интерфейса идёт через ключи Fluent. Но в M0 нет `slam-text` и шрифтов, а оверлей нужен уже сейчас, чтобы мерить движок.
- Tracy нужен для разработки. С настройками `tracy-client` по умолчанию клиент запускается до `main`. Он копит события в памяти, пока не подключится просмотрщик, объявляет себя по всей локальной сети и ставит обработчики сигналов.

## Решение
- **Оверлей фреймтайма — инструмент разработчика, а не интерфейс игрока.** Его подписи не локализуются: это технические ASCII-метки (`DRAW`, `UPDATE`, `INPUT`, `P50`, `MS`, `HZ`). Рисуются они встроенным растровым шрифтом 3×5 из цифр и нескольких заглавных букв. Шрифт растеризуется в целом масштабе, кладётся в атлас и рисуется 1:1 по целым пикселям. Исключение из ADR-0011 касается только таких отладочных оверлеев. Всё, что видит игрок в обычном интерфейсе, по-прежнему идёт через Fluent.
- **Статистика.** Фреймтайм — это интервал между началами кадров (`FrameWait::woke_ns`). Последние 4096 значений хранятся в кольце. Перцентили считаются по ближайшему рангу последовательными выборками `select_nth_unstable` на заранее выделенном буфере. Пересчёт идёт раз в 250 мс и занимает единицы микросекунд.
- **Частоты потоков.** Update и draw публикуют свои счётчики в `EngineCounters`: relaxed-атомики, один писатель на поле, каждое поле на своей паре кэш-линий. `slam-input` считает возвраты `SDL_WaitEvent` (`InputCounters::polls`) и поставленные в кольцо события. Оверлей читает счётчики только при пересчёте.
- **Tracy** подключается через cargo-фичу `tracy` крейта `slam-engine`, по умолчанию выключенную. Без фичи макросы `zone!`/`plot!` и `frame_mark` раскрываются в пустоту. Зависимость `tracy-client` подключена без функций по умолчанию, с `enable`, `manual-lifetime`, `ondemand` и `only-localhost`:
  - клиент работает только после `profiling::start()`;
  - данные пишутся только при подключённом просмотрщике;
  - клиент слушает только localhost.

## Последствия
- Оверлей доступен в M0 без шрифтовой подсистемы. Когда появится `slam-text`, его можно перевести на обычный текст, локализация при этом не нужна.
- Профильная сборка с Tracy аллоцирует один раз на каждое место вызова `zone!` при первом входе (ленивое описание места в `tracy-client`). Тесты «ноль аллокаций» верны для сборки без фичи и для сборки с фичей без запущенного клиента.
- В `just clippy` и в CI добавлена проверка `slam-engine` с `--features tracy`. `cargo deny` собирает граф со всеми фичами.

## Отвергнутые варианты
- **Ключи Fluent для подписей оверлея.** Растровый шрифт не нарисует перевод, а `slam-text` ещё нет. Переводить технические метки незачем.
- **`tracy-client` с настройками по умолчанию.** Память копится без ограничений, пока просмотрщик не подключён, клиент слышен в сети и ставит обработчики сигналов.
- **Пересчёт перцентилей по гистограмме с логарифмическими корзинами.** Он стоит O(1) на кадр, но даёт приближённые значения. Точная выборка раз в 250 мс укладывается в бюджет кадра при 8000 FPS.
