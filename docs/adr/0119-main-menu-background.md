# ADR-0119: Фон главного меню — фон карты из музыки меню или фон скина

- Статус: Принято
- Дата: 2026-11-14

## Контекст
Главное меню рисует только цвет очистки. В меню уже играет музыка случайной карты (ADR-0090), на выборе песни есть загрузчик и плавная смена фонов карты (ADR-0066, `BackgroundLoader`/`BackgroundFade`). Реестр скина знает `menu-background`, но его никто не рисует — #364.

## Решение
- **Настройка** `general.menu_background`: `beatmap` (по умолчанию), `skin`, `none`.
- `beatmap` — фон карты, чья музыка играет в меню; меняется вместе с треком, тем же загрузчиком и плавной сменой, что на выборе песни. Нет фона у карты — фон по умолчанию (ADR-0076).
- `skin` — `menu-background` из цепочки скина (как изображение интерфейса, ADR-0110: не декодируется — как отсутствующий); нет в скине — фон по умолчанию.
- `none` — цвет фона схемы (ADR-0117).
- Затемнение фона меню — токен темы (0,5), отдельной настройки нет. Фон под меню рисуется без слайда перехода, как на выборе песни.

## Последствия
- Меню и выбор песни делят загрузчик фонов; переход меню → выбор песни с той же картой не мигает.
- Заставка (ADR-0114) идёт поверх фона меню.

## Отвергнутые варианты
- Слайдшоу фонов случайных карт: фон не совпадал бы с музыкой.
- Фон скина как изображение `menu-background@2x` с параллаксом: §12 без параллакса.
