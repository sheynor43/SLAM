# Built-in fonts

Variable TrueType fonts from [google/fonts](https://github.com/google/fonts),
unmodified, embedded into the SLAM binary.

| Directory | Font | Source | Upstream commit |
|---|---|---|---|
| `nunito-sans/` | Nunito Sans (UI text) | `ofl/nunitosans/NunitoSans[YTLC,opsz,wdth,wght].ttf` | `8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5` |
| `exo2/` | Exo 2 (headings) | `ofl/exo2/Exo2[wght].ttf` | `1796e34455b893092713d206e7f23e3e07699f00` |

- Both fonts are licensed under the SIL Open Font License, Version 1.1; the full
  licence text with the copyright notice is in `OFL.txt` next to each font.
- **These fonts are not covered by the MIT / Apache-2.0 licence of the SLAM
  source code.**
- Changes: the files were renamed (the axis list in brackets was replaced with
  `-VariableFont`); the font data is unmodified. No Reserved Font Name is
  declared by either font.
